# Phase 3：本地执行基础

## 目标

建立可恢复、可审计的本地任务执行基础。当前阶段只允许读取项目和执行白名单范围内的本地命令，不自动修改项目文件。

## 节点

1. SQLite 任务状态与事件持久化
2. 项目目录安全访问与只读检查
3. 受控命令执行、超时、取消与审计记录
4. Electron 展示任务历史和检查结果

每个节点需通过对应自动检查；整个 Phase 3 还需 Electron 交互验证和用户手动批准。

## 当前边界

- SQLite 使用 Python 标准库 `sqlite3`，数据库位于用户数据目录。
- 不接入真实 Agnes，不自动写入、删除或回滚项目文件。
- 命令执行必须经过明确的白名单和工作目录校验。
