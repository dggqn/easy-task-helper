# Phase 1 Execution Specification

- Fixed stack: Electron, React, TypeScript, Python 3.12, and `uv`.
- Test baseline: pytest for Python, Vitest for renderer units, and Playwright
  for milestone-level interaction checks.
- Phase 1 ends only after project selection and placeholder task conversation
  flow pass automated evidence and user manual approval.
- Authority: unrestricted work inside the workspace except deletion of its root.
- CI: GitHub Actions is required once meaningful product checks exist.
- CD: initial endpoint is a local EXE artifact; publication is out of scope.
